使用说明

1. 创建成功后，浏览器访问短链接应收到 302 并跳转到原长链接。
2. 同一长链接重复创建，返回的短码相同（幂等）。
3. 访问不存在的短码，跳转接口返回 404。
4. 本页仅用于阶段1联调，不包含访问统计与限流（阶段2-4）。
